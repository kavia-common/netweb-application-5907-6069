# netweb-application-5907-6069

This workspace contains the NetWeb Application React frontend that connects to a Flask backend API for managing network devices.

- React frontend path: ReactFrontend
- Features: list, create, edit, and delete devices (name, ip_address, device_type, location)
- API integration: Uses environment-based base URL (REACT_APP_API_BASE_URL)
